Loki Setup Notes
================

1. How I started Loki (local Docker run):

   docker run -d --name=loki -p 3100:3100 grafana/loki:2.9.0

2. (Optional) Started Grafana to visualize logs:

   docker run -d --name=grafana -p 3000:3000 grafana/grafana

   Then added Loki as a data source in Grafana at http://localhost:3100

3. Forwarding container logs to Loki:

   Used the Docker Loki logging driver on the hello-devops container:

   docker run --log-driver=loki \
     --log-opt loki-url="http://localhost:3100/loki/api/v1/push" \
     hello-devops

4. Command used to view logs:

   Via Grafana Explore tab, querying: {job="docker"}

   Or directly via the Loki API:

   curl -G -s "http://localhost:3100/loki/api/v1/query_range" \
     --data-urlencode 'query={job="docker"}' | less
